# رحلة الأذكياء 🦉
لعبة أسئلة للأطفال (10–12 سنة) — 100 مرحلة.
تطوير أبو عبدالله الشامي

## بناء ملف APK
1. أنشئ مستودعًا جديدًا على GitHub (مثلاً RihlatAlAzkiya) وارفع كل محتويات هذا المجلد (بما فيها مجلد .github).
2. افتح تبويب Actions — سيبدأ البناء تلقائيًا (حوالي 3–5 دقائق).
3. بعد اللون الأخضر ✅ ادخل على البناء وحمّل ملف RihlatAlAzkiya-APK من أسفل الصفحة، فكّ الضغط وثبّت app-debug.apk.

## تعديل الأسئلة
الأسئلة موجودة داخل app/src/main/assets/index.html في قسم BANK.
